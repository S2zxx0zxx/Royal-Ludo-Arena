# Native Ludo 3D gameplay integration
Baseline main 69f651a891b62b005d52dfc4c9cfb206ea164bf4. Scope: board, dice, pawn, camera/lighting only.
- Source ZIP inspected: 84 variants, same geometry duplicated across formats. Adopt default Kytric CC0 dice v1 (116 welded vertices, 228 triangles) and token v2 (48 welded vertices, 92 triangles), retain all six pips and four existing seat colors, recolor existing three dice skins.
- Original board 20.4 x 20.4, thickness .6, pitch 1.7; incompatible with canonical 15x15 rules. Adapt source voxel slab geometry and thickness ratio, reconstruct 52 track cells and 24 home cells from LudoCore, preserve yards and 8.75% inset; no visual/rules mismatch. Three existing board palettes. No raw board art overwrite.
- Godot source camera orthographic, overhead light. Adapt projection for mobile square board; directional key, ambient shading, fixed camera orientation, separate model tilts. Actual triangle mesh software rendering to cached PNGs; no GPU dependency, no endless render loop. Dice roll visual frames reflect mesh rotations; final face is engine's committed outcome, not physical simulation.
- Existing canonical DOM pawn buttons and event handlers remain, including offline AI, pass/play and authoritative server snapshots. Invalid buttons disabled. Canvas failure retains existing board image/pawn sprites/CSS cube. Reduced motion honored for new effects. No home, store, engine, server or multiplayer rewrite.
- PWA precache local modules/notice; preserve unrelated origin caches. Source notice and SHA-256 recorded. No source Chess material. Optional remaining source variants are not shipped; selected variants are recolored for current skins.
- Physical phone GPU/device performance, Android packaging and deployed PvP are outside this scoped PR; CI Chromium matrix validates actual production page interactions.
